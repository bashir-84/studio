# Brand logo assets

Add up to 20 transparent logo files here.

- Preferred: SVG
- Alternative: transparent WebP or PNG
- Suggested names: `brand-01.svg` through `brand-20.svg`
- Suggested canvas: 600 × 240 px
- Keep clear space around the mark and avoid a white background.

After adding a file, open `components/brands-page.tsx` and replace the matching
`logo: null` value with a path such as `/media/brands/brand-01.svg`.
